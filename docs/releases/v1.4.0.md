# v1.4.0 — 2026-10-30

**Range**: v1.3.0...v1.4.0

## Highlights

관리자 메뉴와 작성 폼을 정리하고, 대시보드에서 기간별 방문자·전화·견적 활동을 확인하도록 개선했습니다.
메인 서비스·작업 사례의 모바일 탐색과 SNS 연결을 개선하고, 공개 페이지의 초기 데이터 전송량과 렌더링 부담을 줄였습니다.
견적 제출 요청과 접수 성공을 분리해 하단 표에서 비교할 수 있습니다.

---

## Added

- 견적 제출 요청을 별도 API로 기록하고 대시보드 하단 표에 표시합니다. 그래프는 접수 성공 건수를 유지합니다. (`admin-form`)
- 네이버 카페 링크를 추가하고 블로그·카페·인스타그램·당근을 공통 아이콘과 링크 구성으로 표시합니다. (`main`)

## Changed

- 대시보드를 고객 활동 차트와 표 중심으로 정리했습니다. 기본 7일, 30일 및 기간 선택으로 최근 6개월을 조회하고 새로고침할 수 있습니다. (`dashboard`)
- 한국 시간 기준 일별 방문자 중복을 서버에서 제거합니다. IP·브라우저 정보의 일별 해시를 사용한 추정치이며, 통계 기록은 6개월 후 삭제하도록 구성했습니다. (`dashboard`)
- 관리자 메뉴를 대시보드·홈화면 관리·서비스 관리·작업 후기 관리 중심으로 재구성하고, 업체 정보는 사이드바에서 여는 모달로 이동했습니다. (`menu`, `info`)
- 관리자 작성·수정 폼을 공통 입력 스타일로 통일하고, 업체 정보 주소 입력에 기존 주소찾기를 적용했습니다. (`menu`, `info`)
- 홈화면에서 소개 문구와 PC·모바일별 좌우 히어로 이미지를 관리합니다. 이미지는 새로 업로드해 크롭한 뒤 저장합니다. (`menu`)
- 서비스 카드를 청소·이사 토글과 설명문 중심으로 변경했습니다. 모바일에서는 가운데 카드와 스와이프·도트를 사용하며, 카드 호버와 토글 이동 애니메이션을 통일했습니다. (`main-service`)
- 작업 사례는 카테고리별 최신 7개와 전체보기 카드로 구성합니다. 전체보기에는 해당 카테고리와 총건수를 표시하고, 이동 후에도 카테고리 선택을 유지합니다. (`main-work-review`)
- 진행 과정을 견적문의·예약확정·작업진행·작업완료로 정리하고 섹션 높이와 등장 시점을 조정했습니다. (`main-process`)

## Fixed

- 관리자에서 수정한 소개 문구를 공개 메인·상세 페이지에 반영하고, 메뉴·제목·검색 및 공유 정보를 일관되게 정리했습니다. (`production`, `content`)
- 고객 리뷰의 메인 표시량을 제한하고 작업 사례 목록을 페이지별로 조회해, 전체 게시글을 초기 화면에 전송하던 문제를 개선했습니다. (`public-performance`)
- 공개 데이터 조회 실패 시 오류를 전달하도록 변경해, 빈 데이터가 정상 결과로 취급되어 ISR 캐시에 반영되는 문제를 방지했습니다. (`isr`)
- 견적 페이지의 초기 서버 렌더링, 메뉴 사전 요청, 방문 기록 중복 요청, 글꼴·이미지 로딩을 조정했습니다. (`public-performance`)
- 업체 연락처의 검색 구조화 데이터를 수정했습니다. (`seo`)
- Docker 이미지 캐시를 named volume에 연결해 컨테이너 교체 시에도 이미지 캐시를 유지합니다. (`infra`)

## Removed

- 대시보드의 콘텐츠 현황 등 불필요한 표시와 미사용 조회·컴포넌트·훅을 제거하고, 관리자 신규·수정 폼의 중복 구현을 통합했습니다. (`dashboard`, `admin`)

## Internal

- 통계 기록에 서버 전용 Supabase 자격증명을 사용하고 방문자 기록 함수의 실행 권한을 제한했습니다. (`analytics`)
- 독점 라이선스(All Rights Reserved)를 추가했습니다. (`license`)

## Compatibility

- **Node.js**: 20.x+
- **Next.js**: 16.2.7 / **React**: 19.2.3
- **Browser**: 모던 브라우저 (Chrome/Safari/Firefox/Edge 최신 안정 버전)
- **DB migration**: 방문자 집계·보관, 히어로 이미지, 서비스 설명, 카페 링크, 견적 제출 요청 집계를 위한 마이그레이션 7건이 포함됩니다. 배포 대상 DB의 적용 여부를 확인해야 하며, 이 릴리스 절차에서는 DB 변경을 실행하지 않습니다.
- **서버 설정**: 통계 수집에 `SUPABASE_SECRET_KEY`(또는 `SUPABASE_SERVICE_ROLE_KEY`), 32자 이상 `ANALYTICS_HASH_SECRET`, `ANALYTICS_TRUST_CLOUDFLARE=true`가 필요합니다. 방문자 집계는 Cloudflare의 실제 IP 헤더를 전제로 합니다.

## Validation

- 타입·린트·포맷 검사 및 Semgrep 보안 검사 통과.
- 단위·통합 테스트 775개 통과, 파일별 커버리지 100%.
- 브라우저 테스트 93개, PC·모바일 E2E 130개 통과. 접근성 자동 검사는 기존 설정상 색상 대비와 `aria-hidden-focus` 항목을 제외합니다.
- 캐시 삭제 후 프로덕션 빌드 통과.
- Lighthouse: 메인·온라인 견적·서비스를 모바일·PC에서 각각 3회 측정해 설정된 성능 기준 모두 통과. PC 성능 점수는 메인 99~100점, 나머지 100점이며 CLS는 모두 0입니다. 로컬 측정값으로, 운영 환경의 실사용자 지표와는 다릅니다.

## Known Issues

- 제출 요청과 성공 건수의 차이는 이탈·통신 실패·차단 등 여러 원인으로 발생할 수 있습니다. 이 통계만으로 Cloudflare 차단 여부를 확정할 수는 없습니다.
