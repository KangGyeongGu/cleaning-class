## Highlights

공개 페이지의 보조 텍스트와 탭 색상 대비를 조정해 WCAG AA 접근성 검사를 예외 없이 통과하도록 개선했습니다.
테스트·성능 검사 체계를 정리하고, 운영 의존성을 최신 보안 버전으로 갱신해 배포 전 검증의 신뢰도를 높였습니다.

---

## Changed

- 공개 페이지의 보조 텍스트·필터 탭 색상 대비를 높여 색상 대비를 포함한 WCAG A·AA 접근성 검사를 통과하도록 개선했습니다. (`public-ui`)
- E2E는 실행마다 새 로컬 production build를 사용하고, 원격 URL 검사는 명시적 승인 환경변수가 있어야만 실행하도록 변경했습니다. (`e2e`)

## Removed

- 더 이상 실행 경로가 없는 독립 SQL 테스트를 제거했습니다. (`supabase-tests`)

## Internal

- ESLint, Vitest, Playwright, Lighthouse, Semgrep 설정을 `config/`로 모으고 각 설정의 실행 시점·목적 주석과 테스트 시스템 안내 문서를 추가했습니다. (`tooling`)
- 접근성 E2E에서 제외했던 색상 대비와 숨김 요소 규칙을 복원하고, 워밍업 HTTP 오류가 테스트 실패로 보고되도록 강화했습니다. (`tests`)
- Next.js, Zod, Nodemailer, Vitest, Lighthouse CI 등 운영·검증 의존성을 보안 패치가 반영된 버전으로 갱신했습니다. (`dependencies`)
- Zod 4 전환에 맞춰 폼 검증 오류 표시와 PostgreSQL 형식 UUID 검증을 호환되도록 조정했습니다. (`validation`)
